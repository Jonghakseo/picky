# Actual-provider projection v2 replay data

`bash.json` and `subagent.json` are test recordings, **not** a wire protocol. Each has `provenance`, `frames` (ordered, complete projection v2 socket frames from registration bootstrap onward), and `checkpoints` (`name`, zero-based inclusive `through` index into `frames`, and selected state read back from the real SessionStore at that revision). Send each `frames` element as a JSON event through the production Swift envelope decoder and registry/v2 application path. At every `through`, inspect the production session, task and composer projections; compare its revision, status, task identities/presence, tickets, and retention to `disk`. Do not apply `disk` as an input. The bootstrap snapshot and bootstrap-complete frame are required; do not start at a checkpoint transaction.

The offline model emits a real `bash_async` or `subagent` tool call from `SessionSupervisor.followUp`; unchanged providers, Pi SDK 0.87.1, PiSdkRuntime, SessionSupervisor, SessionStore and a port-0 AgentdServer generate the events. `subagent` uses a finite local `pi` child over a Unix socket. No nested model or network request runs. `bash` records tool-returned running, settled-execution/pending-ticket (still retained), and handled/settled. `subagent` records handled result while native child remains alive, ordinary follow-up while only that child is active, and actual child exit/settlement. These do **not** cover archive, reconnect, uncertain owner, mixed provider versions, IME, or a live Swift socket/UI.

The original unnormalized frames/checkpoints are in `.audit/pickle-async-tasks/w7-provider-replay-raw/`. Normalization is deterministic across each entire envelope: one-to-one mappings for UUID strings (valid canonical UUIDs), ISO timestamps (valid ISO timestamps), SDK session-file paths (consistent `<fixture-root>/home/.pi/agent/sessions/session-N.jsonl`), the fixture root and its basename. Frame order, revisions, mutations, task identifiers and every other field remain intact. The SDK file paths are inert replay data, not files for Swift to open. `node .audit/pickle-async-tasks/w7-provider-replay-compare.mjs` recomputes the exact mapping from raw files, checks every field plus checkpoint revisions, and verifies source hashes.
