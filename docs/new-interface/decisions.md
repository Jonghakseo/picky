# 새 인터페이스 기획 결정 로그

기존 개발명세(`new-interface-development-spec.md`)와 목업이 비워둔 부분을 대화로 채우면서 남기는 결정 기록. 확정된 항목은 최종적으로 개발명세 본문에 반영한다.

## 확정 결정

### 창 위상 / 메뉴바 관계
- 메뉴바 Picky 아이콘을 클릭하면 이 새 창(사이드바 7메뉴 대시보드)이 열린다. **기존 Companion 패널(상태/플러그인/설정 탭 UI)은 완전히 대체되어 사라진다.**
- 이번 기획 범위는 목업/명세가 비워둔 공백 채우기(fill gaps)다.

### 음성 / 자유 호출
- 기존 헤더의 **마이크 상태 표시는 제거**한다.
- 자유 호출(단축키·음성·텍스트) 진입 방식 자체는 이번 범위에서 손대지 않는다. ("대시보드로 통합"은 마이크 상태 제거 맥락이었고, 호출 UX 재설계가 아님.)

### 기존 푸터 기능(종료 / Dock 숨기기 / 피드백 / 외형 토글)
- **종료·Dock 숨기기·외형 토글**은 메뉴바 아이콘 우클릭 메뉴로 유지.
- 동시에 **새 창 좌측 하단**에도 배치한다(사이드바 하단 영역).

### 최근 대화
- **목업대로** 간다: 통합 타임라인/구분선이 아니라, 가장 최근 대화 하나를 이어보는 형태.
- 이미 존재하는 메뉴바의 '최근 대화'(메인 에이전트 대화)를 그대로 쓴다. 코드상 `companionManager.mainAgentMessages` + 입력 composer(`CompanionPanelMessagesView`)가 그 실체. 새 페이지는 이를 재사용.
- 명세 3.6의 통합 타임라인 문구는 목업/기존 구현 기준으로 수정 예정.

### 통계 작업 유형 분류
- **백그라운드 주기 분류**. 생성 시점 1회 분류가 아니라, 백그라운드 작업이 주기적으로 Pickle 세션들을 훑으며 분류한다(수정·개선 / 조사·분석 / 새로 만들기 / 검토·문제 해결).
- 입력은 저렴한 메타데이터: **사용자 메시지 N개 샘플링 + 도구 호출 빈도** 등. 전체 트랜스크립트를 읽지 않는다.
- 역할 분담: 수집은 **미리 만들어둔 결정적 스크립트**가 담당(샘플링·메타데이터 집계). 모델은 스크립트를 호출하고 압축된 결과만 보고 빠르게 판정한다. 토큰 소모 자체를 최소화하는 플로우.
- 이 구조로 신규·분류 실패·과거 Pickle 소급이 모두 같은 주기 작업 하나로 처리된다. 별도 재시도 경로 불필요.
- **미분류 표시(A)**: 아직 분류되지 않은 Pickle은 통계에서 '미분류' 버킷으로 표시해 합계를 항상 맞춘다. 주기 분류가 돌면 자연스럽게 줄어든다.

### 가이드/업데이트 콘텐츠 소스
- **앱 번들**. 빌드에 고정 JSON 포함(제목·발행일·유형·썸네일·YouTube URL). 갱신은 앱 업데이트로.

### 통계 카운트 소스
- **기존 기록에서 파생**. Pickle 세션 번들의 메시지/툴 기록을 집계해 후속 지시 수·Picky 위임 수·검토 수를 계산. 집계 전용 계측을 새로 심지 않는다.

### 빠른 시작 워크플로우
- **Pi가 주도**. 워크플로우별 진행 가이드를 Pickle에게 제공하면 Pi가 그대로 수행(필요한 정보를 한 질문씩 수집). 고정 질문 폼은 두지 않는다.
- **저장 위치: 앱 번들 문서(B)**. 워크플로우별 가이드 마크다운을 앱에 포함하고, 시작 시 Pickle 첫 지시에 실어 보낸다. 스킬화(A)는 나중에 필요해지면 재검토.
- 가이드 형식: 각 워크플로우는 구현 방법·목적 등 큰 그림을 잡는 **질문 주제 5~7개**를 명시한다. Pi는 이 주제들을 한 번에 하나씩, 이전 답변에 맞춰 조정하며 진행한다.
- 4종 초안 방향: 랜딩 페이지(제품·핵심 메시지·톤·배포), 네이티브 앱(플랫폼·핵심 기능·실행 범위), 앱 가이드(현재 앱 화면 맥럽·목적별 단계 안내), 파일 정리(대상 폴더·정리 기준).

### 설정 페이지 구성
- **목업 7그룹**을 따른다: 일반 / 계정·에이전트 / 음성·입력 / 화면·오버레이 / Pickle·작업공간 / 알림·권한·개인정보 / 고급·진단. 명세 3.7의 4섹션 문구는 목업 기준으로 수정 예정. 기존 `PickySettingsStore`에 매핑한다.

### 반응형
- 창은 **리사이즈 가능**.
- 최소 크기 **760×560**. 이보다 작게는 못 줄임.
- 사이드바는 **190px 고정**(라벨 포함). 아이콘 모드 없음.
- 카드 열: 본문 폭 기준 ~640px 이상 3열 / 460~640px 2열 / 460px 미만 1열 (카드 최소 폭 약 280px 기준 역산).
- 통계 표·설정 리스트 등 카드가 아닌 페이지는 폭에 맞춰 늘어나기만 하면 됨(열 전환 불필요).

### 창 재사용
- **단일 창 재사용**. 창은 항상 하나만 존재.
- 메뉴바 아이콘을 누르면: 없으면 생성, 이미 있으면 **앞으로 가져오기(포커스)**. 토글 아님 — 떠 있는데 다시 눌러도 숨지 않는다.
- 보던 페이지·스크롤 위치는 유지. 숨기거나 닫기는 창 닫기 버튼/Cmd+W로.
