# Picky 새 인터페이스 유저 플로우

## 1. 홈 진입

Picky 실행 → 대시보드

- 인사말을 확인한다.
- 이번 주 Picky와 한 일을 돌아본다.
- 가이드·업데이트와 빠른 시작으로 다음 활용법을 찾는다.
- 통계가 없는 첫 사용자에게는 `아직 이번 주 기록이 없어요` 카드가 보인다.

## 2. 통계로 사용 패턴 보기

대시보드 통계 카드 또는 사이드바 `통계` → 기간·프로젝트 선택 → `작업` 또는 `AI 사용량`

- 작업 보기에서 가장 많이 맡긴 일, 가장 깊게 진행한 Pickle, 가장 집중한 프로젝트를 확인한다.
- 작업 유형 분포와 Pickle별 상호작용 기록을 읽는다.
- AI 사용량 보기에서 토큰 추이와 모델·제공업체별 사용량을 확인한다.
- 통계의 Pickle 기록은 읽기 전용이며, 작업 상세로 이동하지 않는다.

## 3. 가이드와 업데이트 보기

대시보드 또는 사이드바 `가이드 및 업데이트` → 카드 선택 → YouTube 영상 모달

- 가이드와 제품 업데이트를 최신순으로 훑는다.
- 카드를 누르면 앱 안에서 영상을 재생한다.
- 닫기 또는 `Esc`로 모달을 닫고 원래 피드로 돌아간다.

## 4. 빠른 시작으로 작업 만들기

대시보드 또는 사이드바 `빠른 시작` → 대표 워크플로우 선택 → 새 Pickle 작업 화면

- 워크플로우가 한 질문씩 필요한 정보를 묻는다.
- 사용자는 답변을 제공하고, Picky는 답변에 따라 다음 질문을 조정한다.
- 정보가 충분해지면 Pickle 작업을 실행한다.
- 중간에 멈춘 작업도 나중에 같은 Pickle에서 이어간다.

## 5. 자유롭게 Picky 호출하기

단축키·음성·텍스트로 기존 Picky 호출창 열기 → 요청 입력 → 대화 또는 작업 진행

- 자유 요청은 대시보드의 별도 CTA가 아니라 기존 Picky 호출 방식에서 시작한다.

## 6. 플러그인 찾기와 설치

사이드바 `플러그인` → 카테고리 탐색 또는 검색 → 플러그인 선택 → 상세 모달 → 설치

- 홈에서는 추천 플러그인을 바로 설치할 수 있다.
- 카탈로그에서는 상세 모달로 내용을 확인한다.
- 설치 성공 시 즉시 `설치됨` 상태가 표시된다.
- 설치 실패 시 원인과 재시도 행동을 확인한다.

## 7. 최근 Picky 대화 이어가기

사이드바 `최근 대화` → 메인 에이전트와의 가장 최근 대화 → 하단 composer로 이어쓰기

- 메인 에이전트와 주고받은 가장 최근 대화 메시지를 말풍선으로 읽는다.
- 하단 입력창으로 그 대화에 이어서 새 메시지를 보낸다.
- 통합 타임라인·대화 구분선은 두지 않는다(기존 메뉴바 '최근 대화' 그대로).

## 8. 설정 관리

사이드바 `설정` → 섹션 선택 → 값 변경 또는 권한 확인

- 계정과 AI 연결을 관리한다.
- 화면 기록·마이크·접근성 권한과 개인정보 설정을 확인한다.
- 음성·단축키·알림·화면 지시 방식을 바꾼다.
- 필요할 때만 고급/진단에서 오류와 기록을 확인한다.

## 9. 화면 전환 원칙

- 사이드바 메뉴는 항상 독립 페이지를 연다.
- 좁은 창에서는 카드 열과 사이드바가 축소되지만, 핵심 메뉴와 행동은 유지된다.
- 모달을 닫으면 사용자는 이전 위치와 포커스로 돌아간다.
