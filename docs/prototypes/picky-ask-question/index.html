노란 warning 틀. design/COMPONENTS.md의 "입력 필요를 warning과 혼동하지 않게" 규칙 위반중립 바탕 + Action Blue 테두리 한 줄, 제출 버튼도 같은 파랑
radio와 checkbox가 똑같은 버튼이라 몇 개 골라야 하는지 모른다원 / 네모 표시 + "여러 개 고를 수 있어요" 힌트
"기타…" 버튼과 늘 보이는 비활성 입력칸이 따로 있다"직접 입력" 행을 고르면 그 행 안에 입력칸이 열린다
제출·취소 무게가 같고, 제출이 꺼진 이유가 안 보인다제출 = 주 버튼, 건너뛰기 = 글자 버튼, 꺼진 이유를 옆에 표시
질문 여러 개가 한 버블에 세로로 쌓인다2개 이상이면 단계 진행(메인 질문 패널과 같은 규칙), 앞 답은 칩
답한 뒤 접히면 무엇을 골랐는지 남지 않는다접힌 줄에 답 요약, 펼치면 질문·답 두 열
Mac 키보드 조작이 없다숫자 키 1–9 선택, ↩ 다음·제출, 메인 패널은 esc 건너뛰기
메인 Picky 패널은 커서 옆에 뜨는데 누가 묻는지 안 보인다"Picky가 물어봐요" 머리줄, "말로 답해도 돼요" 안내
