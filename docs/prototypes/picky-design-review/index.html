대화와 작업 상태가 먼저 보이는 UI

기존 Picky 디자인 기준을 브라우저에서 비교할 수 있게 구성했습니다. 아래 값은 HTML용 제안이며, macOS의 글꼴 배율·재질·접근성 구현을 검증한 것은 아닙니다.

Picky 디자인 기준canonical tokens컴포넌트 계약Apple macOS HIG ↗

첫 시선의 순서

  1. 실행 중인 Pickle, 입력 대기, 완료 또는 실패를 형태와 이름으로 구분합니다.
  2. 사용자가 할 수 있는 행동에만 Action Blue를 씁니다.
  3. 도구 활동, 질문, 오류와 결과는 내용보다 뒤로 숨기지 않습니다.

이번 브라우저 검수 범위

라이트·다크, 1440/1024/390 폭, hover/pressed/disabled, keyboard, Reduce Motion과 높은 대비를 시연합니다. VoiceOver, IME, native font scaling, material, HUD 성능은 native 구현에서 별도 확인해야 합니다.

적용 전 확인

  • 행동의 파란 버튼과 작업 중인 진행 링을 형태로 구분합니다.
  • 일반 control은 arrow cursor와 hover state를 사용합니다. pointer는 실제 링크에만 둡니다.
  • 일반 card와 button에 glow를 추가하지 않습니다.
  • details와 management는 같은 right slot을 공유하며 wide size에서 conversation 옆에, 1100px 이하에서 conversation을 대체합니다.
