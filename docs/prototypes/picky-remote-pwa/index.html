Picky 원격 PWA · 컴포넌트 시안 검수 보드

왼쪽은 폰 시안(390pt), 오른쪽은 같은 부분의 HUD 렌더 갤러리 이미지입니다. 대화방은 HUD와 똑같이 보여야 하고, 방 목록만 새 디자인입니다. 계획: docs/remote-pwa-plan.md "화면" 절.

검수 때 볼 것

  • 대화방 파트에서 HUD와 다른 점. 폰에 맞춰 일부러 바꾼 것은 hover 대신 탭으로 보이는 시각과 아이콘, 44pt 터치 영역, Option+Return 대신 보낼 시점 메뉴, 받아쓰기 중 esc 대신 취소 버튼, 받아쓰기 실패·권한 안내를 자르지 않고 줄바꿈한 것, 설정 시트의 단축키 안내 제거, 중지 선택을 폰 알림으로 그린 것입니다.
  • 폰 마이크(정함): 폰에서 녹음하고, 맥이 자기 음성 인식 서비스와 언어 설정으로 받아씁니다. 그래서 권한 안내가 폰 마이크(입력창 상태 11)와 맥 음성 인식(상태 12) 두 가지입니다. 폰 안내 문구가 실제 iPhone 설정과 맞는지는 실기기로 확인합니다.
  • 작업 패널 버튼은 결과물·변경사항 탭만 엽니다(터미널 탭 제외). 도구가 읽은 이미지와 대화 속 파일 링크는 맥에 있는 파일이라, 폰에서는 gateway가 이 세션에 기록된 경로만 보여 줍니다. 파일 링크를 누르면 읽기 전용 미리보기가 열립니다(정함). 미리보기 화면은 화면 목업 단계에서 만듭니다.
  • 방 목록 기본안: Picky 방 고정, 최근 활동 순, 그룹 필터, 맥과 읽음 공유. Picky 방에도 상태 줄을 보여 줄지.
  • 새 문구와 빌려 쓴 문구: new-strings.md. 방 목록 제목은 지금 Hub 메시지 화면의 "메시지"를 빌려 씁니다.
  • 질문 머리줄의 ⌑ 입력이 필요해요 · confirm처럼 내부 method 이름이 보이는 것은 HUD도 같습니다. 바꾸려면 HUD와 함께 바꿉니다.

오른쪽 이미지는 저장소에 없습니다. 대부분은 ./scripts/render-ui-gallery.sh messenger-ux, conversation-activity, conversation-context, dock-group으로 만듭니다. 컴포저(composer-production)와 도구 이미지(read-image)는 해당 기능을 만들 때 목업 런북 하네스로 렌더한 production 이미지입니다(README 참고).
