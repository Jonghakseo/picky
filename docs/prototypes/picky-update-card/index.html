대시보드 원버튼 업데이트

새 버전이 나오면 Hub 대시보드 맨 위에 알려주고, 버튼 한 번으로 설치와 재시작까지 끝낸다.

지금 문제

  • Picky는 LSUIElement 앱이다. Sparkle이 4시간마다 새 버전을 찾으면 기본 알림 창을 띄우는데, Dock 아이콘이 없어서 다른 창 뒤에 묻히기 쉽다.
  • Info.plist에 SUAutomaticallyUpdate가 없어서 자동 다운로드가 꺼져 있다. 업데이트하려면 알림 창 → 설치 → 다운로드 대기 → 재시작까지 여러 단계를 거친다.
  • Hub에서 업데이트 관련 UI는 설정의 업데이트 확인 버튼뿐이다. 새 버전이 있는지는 눌러봐야 안다.

제안 흐름

예약 확인 (4시간)→ 백그라운드 다운로드→ 대시보드 카드 “업데이트 준비됨”→ [업데이트하고 재시작]→ 진행 중 Pickle 있으면 확인 창→ agentd 정지 · 설치 · 재실행

카드를 무시해도 손해가 없다. 다운로드가 끝난 업데이트는 다음에 Picky를 종료할 때 Sparkle이 설치한다. 그래서 설명 문구에 “다음에 종료할 때 설치돼요”를 적어 “나중에”를 눌러도 안심하게 한다.

배치

인사 카드 바로 아래, 권한 안내 카드보다 위에 둔다. 권한 카드는 “해야 Picky가 동작하는 일”이고 업데이트 카드는 “하면 좋은 일”이라 우선순위를 고민했는데, 권한 카드는 첫 설치 직후에만 뜨고 업데이트 카드는 수주마다 뜬다. 둘이 동시에 보일 일이 거의 없어서 시선 위치를 우선했다. 동시에 뜨면 권한 카드를 위로 올리는 쪽도 괜찮다.

색은 Action Blue 틴트 한 가지만 쓴다. 경고색(노랑)을 쓰면 “문제가 생겼다”로 읽히는데, 업데이트는 문제가 아니다. 실패 상태에서만 danger 틴트로 바꾼다.

구현 메모

  • 진짜 원버튼의 전제: Info.plist에 SUAutomaticallyUpdate = YES를 넣어 기본값을 자동 다운로드로 바꾼다. 그래야 카드가 뜰 때 이미 파일이 받아져 있고, 버튼이 곧바로 설치 + 재시작이 된다. Sparkle 2.9.1 헤더에서 SPUUpdaterDelegate의 willInstallUpdateOnQuit:immediateInstallationBlock:를 확인했다.
  • PickyUpdaterController에 @Published var dashboardUpdate: DashboardUpdateState를 추가한다. 델리게이트 콜백은 nonisolated이므로 기존 updaterWillRelaunchApplication처럼 MainActor로 넘긴다. immediateInstallationBlock은 상태 안에 보관한다.
  • Sparkle 팝업 중복을 막기 위해 SPUStandardUserDriverDelegate를 달고 supportsGentleScheduledUpdateReminders = true, 예약 확인에서 찾은 업데이트는 standardUserDriverShouldHandleShowingScheduledUpdate에서 false를 돌려 카드로만 알린다. 메뉴·설정의 “업데이트 확인”처럼 사용자가 직접 누른 경우는 지금처럼 Sparkle 창을 쓴다.
  • 재시작 직전에는 기존 willRelaunchApplication 훅이 agentd를 멈춘다. 이 흐름은 그대로 탄다.
  • 진행 중 Pickle 판단은 세션 상태가 running / tool 실행 / 입력 대기인 것만 센다. 확인 창은 기존 PickyHubModalHost로 띄운다.
  • “나중에”는 버전 문자열을 PickySettings에 저장해 같은 버전 카드만 숨긴다. 더 새 버전이 나오면 다시 뜬다.
  • “새 기능 보기”는 appcast 항목의 releaseNotesURL/fullReleaseNotesURL이 있을 때만 보인다.
  • Hub를 열 때 마지막 확인이 1시간 넘게 지났으면 checkForUpdatesInBackground()를 한 번 호출해 카드가 늦게 뜨는 일을 줄인다(선택).

정해야 할 것

자동 다운로드를 기본으로 켤지. 켜면 진짜 원버튼이 되고, 끄면 “수동” 상태가 기본이 되어 버튼을 눌러도 Sparkle 창을 한 번 더 거친다. 저는 켜는 쪽을 추천한다. 설정의 “자동 업데이트 확인” 토글 옆에 “업데이트 자동으로 받기” 토글을 추가해 끌 수 있게 하면 된다.

범위 밖: 메뉴 막대 패널과 HUD 도크의 업데이트 배지는 이번 범위에서 뺐다. 대시보드 카드가 자리 잡은 뒤 필요하면 추가한다.
